Answer the filter above against the index. Typical asks: what is open in a
given epic, what is unblocked right now, what is P0, what is small enough to
fit in the time available.

When reporting:

- **Lead with what is unblocked.** An item whose dependencies are all done is
  actionable; one that is blocked is not, however attractive its points look.
- **Quote the point value as effort only.** Never suggest a tier, never
  suggest which build agent applies, and never call something "simple" or
  "safe" on the basis of its points. Tier is assigned by `arch` against the
  project's T3 floor after planning, and a 1-point change to a critical path
  is still critical.
- **Name the blockers explicitly** when something is blocked, so the human can
  see what would have to move first.
- Read `items/<ID>.md` only for items the human asks about specifically. Do
  not read all of them to answer a question about the list.

End with the candidate IDs and nothing more. The human picks; when they have,
they run `/plan <ID> <what they want>` themselves. Do not offer to start
planning, and do not switch agents.
